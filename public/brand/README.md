# BhuMi brand assets

`bhumi-logo.png` is the original PNG supplied by the project owner. It is preserved unchanged. The compact symbol and browser/touch icons are cropped and resized exports with the original white background retained for legibility in both themes.

Run `node scripts/brand-assets.mjs` after installing dependencies to reproduce the exports. The shared Brand component supplies the header, footer and printable reports. Non-brand parcel/layer icons remain interface symbols.

# Demonstration guide

## Ninety-second recording

- **0–12s:** Dashboard: “A correct total can hide an incorrect owner allocation. These are fictional records.”
- **12–28s:** Open DEMO-P4-001; show the baseline and expand the sale from Owner A to Buyer D.
- **28–48s:** Run reconciliation. Point to equal 120 totals, B −15 and D +15; show deed/event references.
- **48–63s:** Create a review case, begin review, record a note requesting corrected mutation evidence.
- **63–82s:** Append a snapshot with A 1/4, B 1/3, C 1/6, D 1/4, E 0. Rerun and show MATCH.
- **82–90s:** Select the earlier run: its original findings remain. “BhuMi supports a human decision; it does not determine legal title.”

Rehearse before recording. Do not claim the video has been recorded or submitted; this repository contains the script and working demonstration.

## Prepare for questions

- **Does MATCH prove title?** No. It means supplied records reconcile under explicit assumptions.
- **Does this decide inheritance?** No. Allocations and supporting evidence must already be supplied.
- **Why fractions?** Thirds and sixths remain exact; display rounding cannot change the result.
- **Can a reviewer hide a finding?** Workflow resolution does not modify the saved calculation. Database administrators remain trusted; this is not tamper-proof storage.
- **Does it connect to government systems?** No. Only synthetic local data are used.
- **What scales next?** Authorized data extracts, domain-reviewed templates, hosted PostgreSQL and institutional access control, each independently validated.
